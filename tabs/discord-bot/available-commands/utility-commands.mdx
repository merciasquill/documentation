## Setup Command

### Features Subcommand Group

#### Custom Profile Subcommand

<>
  <Badge color="purple" icon="star">
    Tier 2 Premium
  </Badge>
  {" - "}
  <Badge color="green" icon="server">
    Guild Install
  </Badge>
  {" - "}
  <Badge color="yellow" icon="clock">
    Cooldown: 30m
  </Badge>
  {" - "}
  <Badge color="red" icon="lock">
    Required Permissions: Manage Server
  </Badge>
</>

```
/setup feature custom_profile
```

> This command can be used to configure a custom server-specific profile picture, name, description, and banner for Mercia's Quill.

Please note that this change will be visible to _all members_ in the server. Misuse by using inappropriate content may result in a permanent restriction of this feature by the server.

#### Wiki.gg Domain Lock Subcommand

<>
  <Badge color="green" icon="server">
    Guild Install
  </Badge>
  {" - "}
  <Badge color="yellow" icon="clock">
    Cooldown: 10s
  </Badge>
  {" - "}
  <Badge color="red" icon="lock">
    Required Permissions: Manage Server
  </Badge>
</>

```
/setup feature wikigg_lock
```

> This command can be used to configure a message rule which automatically redirect all deprecated [seaofthieves.fandom.com](https://seaofthieves.fandom.com) links to [seaofthieves.wiki.gg](https://seaofthieves.wiki.gg).

### Moderation Subcommand Group

#### Alternate Account Gate Subcommand

<>
  <Badge color="green" icon="server">
    Guild Install
  </Badge>
  {" - "}
  <Badge color="yellow" icon="clock">
    Cooldown: 10s
  </Badge>
  {" - "}
  <Badge color="red" icon="lock">
    Required Permissions: Manage Server
  </Badge>
</>

```
/setup moderation alt_account_gate
```

> This command can be used to configure a user moderation rule which prevents users from joining servers using alternate accounts. This feature relies on a [verification system](/tabs/guides/verification-systems/overview) to be in place.
