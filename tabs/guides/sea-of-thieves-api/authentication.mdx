## Terminology

<Card icon="cookie-bite" href="https://web.dev/articles/understanding-cookies" cta="Learn more">
  ### Cookies

Cookies are small pieces of data stored by the browser and automatically sent
with requests to the server. The [seaofthieves.com](https://seaofthieves.com)
uses cookies to:

- Identify the currently authenticated account.
- Persist the current login session across visits.
- Store security and privacy preferences.

Cookies are included with requests to authenticate the current session.

</Card>

<br />

<Card icon="code" href="https://react.dev/learn" cta="Learn more">
  ### React `APP_PROPS`

`APP_PROPS` is a JavaScript object embedded in the React application page. It
contains page-level values used by the application, including the CSRF token.
The object becomes accessible only after the DOM has loaded.

</Card>

<br />

<Card icon="key" href="https://auth0.com/docs/secure/tokens/access-tokens/json-web-encryption" cta="Learn more">
  ### JSON Web Encryption

JSON Web Encryption (JWE) is a standard for transmitting encrypted data. The
[seaofthieves.com](https://seaofthieves.com) uses JWE to store and update the:

- [RAT token](#rat-token).

The `rat` JWE is included in the authentication cookie and authenticates
requests for the current session.

</Card>

## Authentication Values

### RAT Token

<Badge color="green">GET</Badge> <Badge color="blue">POST</Badge>
<Badge color="yellow">PUT</Badge> <Badge color="red">DELETE</Badge>

The `rat` cookie is the primary authentication credential for
the [seaofthieves.com](https://seaofthieves.com) website and its internal APIs.

- Format: [JSON Web Encryption](#json-web-encryption)
- Stored as: `rat` [cookie](#cookies)

The browser automatically includes this token in requests to the Sea of Thieves
API. It is required for all login-protected endpoints and must be kept secure.

<Danger>
  The RAT token functions like a password and can provide full account access
  until the password is reset or the token expires after six days.
</Danger>

### User-Agent

<Badge color="green">GET</Badge> <Badge color="blue">POST</Badge>
<Badge color="yellow">PUT</Badge> <Badge color="red">DELETE</Badge>

The `User-Agent` identifies the client software and device that make the request.

- Format: Plain Text
- Stored as: Generated headers

The `User-Agent` header is required for every request to prevent bot abuse challenges issued by Azure.

### Referer

<Badge color="green">GET</Badge> <Badge color="blue">POST</Badge>
<Badge color="yellow">PUT</Badge> <Badge color="red">DELETE</Badge>

The `Referer` header identifies the page from which the request originated.

- Format: URL
- Stored as: Generated headers

The path does not matter. The URL must use the
`https://www.seaofthieves.com/` domain and must end with a forward slash (`/`).

### CSRF Token

<Badge color="blue">POST</Badge> <Badge color="yellow">PUT</Badge>
<Badge color="red">DELETE</Badge>

The CSRF token protects state-changing requests from cross-site request
forgery.

- Format: Plain Text
- Stored as: React [`APP_PROPS`](#react-app_props)

The token is stored in `APP_PROPS` and becomes accessible only after
the DOM has loaded. Include it in the `X-CSRF-Token` header for every
POST, PUT, or DELETE request.

## Example Requests

<CodeGroup dropdown>

```bash get_request_example.sh
curl 'https://www.seaofthieves.com/api/endpoint' \
  -H 'Cookie: rat=...' \
  -H 'User-Agent: Mozilla/5.0' \
  -H 'Referer: https://www.seaofthieves.com/'
```

</CodeGroup>

<CodeGroup dropdown>

```bash put_request_example.sh
curl 'https://www.seaofthieves.com/api/endpoint' \
  -X PUT \
  -H 'Cookie: rat=...' \
  -H 'User-Agent: Mozilla/5.0' \
  -H 'Referer: https://www.seaofthieves.com/' \
  -H 'X-CSRF-Token: ...'
```

</CodeGroup>
